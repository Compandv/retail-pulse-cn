# 跟风追涨表达试验与复核（2026-09-19）

## 本轮范围

新增独立版本 `behavior-audit-0.1`，接入现有日报生成流程与表达卡片。旧韭菜分和排序仍按保存口径展示，不重写旧分；未来生成的日报附带试验指标。用户要求试改，因此先用已有真实采集记录验证，而不是用截图调权重或宣称准确率已经提高。

## 定义与发布

- 目标：本人明确表达跟随买入、追涨执行或追涨计划，账户只计一次，不叠加多个标签。
- 可判断非目标：严格匹配的明确不追买、观望自述或单纯询问。普通文本未命中不自动归为非目标。
- 未知：明确截断、条件／转述／历史语境、规则未覆盖、账户证据冲突、未进入样本。每账户归入一个未知原因；各原因之和等于未知账户。
- 比例：目标账户 / 可判断账户 × 100；同时保存目标占全部观察账户比例、可判断账户数和判断覆盖率。
- 初始保护门槛：可判断账户至少20、判断覆盖至少80%、原有来源及身份门槛通过。门槛未经人工校准，符合也只称试验比例。
- 一账户最多3条去重文本。同账户正反证据冲突保留未知；普通含糊文本不能被强行解释为理性。不同平台账户不做跨平台身份合并。

未知原因是规则审计结果，并非已确认真实原因。没有文本截断标识不代表正文完整；标题也可能是完整发言。覆盖门槛不能消除非随机采样偏差，统计只针对观察范围。

## 离线复核

```powershell
python scripts/audit_behaviors.py --capture work/report-observations/2026-09-15.json
python scripts/evaluate_behaviors.py work/behavior-audit/2026-09-15/review-sample-blind.jsonl
```

Python需使用真实安装路径，不能使用不工作的WindowsApps别名。脚本不联网、不调用模型、不覆盖公开快照。

输出在Git忽略的 `work/behavior-audit/<日期>/`：对照HTML、完整报告预览、指标摘要、默认500条复核样本，以及独立的规则预测文件。复核样本不含账户标识，也不展示机器预标注，避免诱导人工判断；包含公开原文和链接，仍应本地保管。归一化文本去重后按日期和文本哈希稳定抽样，不是按账户／股票分层的代表性调查，因此不能直接估计全市场比例误差。重复运行不覆盖已有人工标注文件。

`humanLabel` 填 `target`、`non_target` 或 `unknown`，不确定留空；可另填理由及标题／正文各自判断，供对照。评测只读取人工标签，重新执行当前分类器，输出目标精确率、召回率和混淆矩阵；拒绝重复标注ID和非法标签。未标注不产生准确率，未知预测计入漏检。

## 验收与后续

- [x] 全部明确追涨样本可得到100%的试验比例，而不是旧量表的40分。
- [x] 20目标＋30非目标＋50未知得到条件比例40%、判断覆盖50%，不发布试验值。
- [x] 重复帖子不增加账户权重；条件、转述、历史不作本人当前行动。
- [x] 原有日报与旧快照兼容；审计按新增独立版本保存。
- [x] 离线生成真实数据对照和待人工复核集，不伪造人工标签。
- [ ] 人工复核并独立留出跨日期、跨账户测试集。
- [ ] 验证标题与正文的实际误差差异，再决定扩充正文预算。
- [ ] 增加分层采样和平台人气候选源，单独校验接口与采样偏差。
- [ ] 比较中文小模型与规则在同一测试集的性能，达标后才考虑替换正式评分。

本轮实现审计与试验闭环，没有宣称解决全部采集覆盖问题，也没有把规则命中率当作语义准确率。

## 实测结果

9月4日及9月15日已离线回放成功，各生成500条待复核文本。9月15日前十题材的试验判断覆盖为0.0%～0.4%（显示值取一位小数），均未达到发布门槛。少数可判断样本全部为目标表达，条件比例出现100%，但不作为板块分数展示。这证明严格自述规则在真实口语中覆盖很弱，也证明不能通过剔除未知账户直接得到可靠的综合分。旧分类未知率与新行为判断覆盖对应不同任务，不能直接比较。

当前没有人工标注，因此准确率、精确率及召回率为空。已通过104项Python测试、35项原有前端测试及2项新增真实组件渲染测试、生产构建、TypeScript类型检查和ESLint。程序边界通过不代表语义效果达标。
