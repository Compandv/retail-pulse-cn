本次为兼容现有快照的增量升级，不替换 React/vinext + Python + JSON 架构，不增加运行依赖，不接入新模型或自动任务。借鉴同类项目将事实计算与模型解读分开的设计，代码为本项目独立实现，没有复制第三方项目源码。

## 一、共享定义

`config/following.json` 集中保存跟风追涨公式、标签、每账户上限、最小账户数、追买行动/计划强度和未知率门槛。`sentiment/following.py` 与 `lib/following-method.ts` 读取同一份文件。方法页、本地问答、题材表达表及分数说明共用这一解释。

本次不改变既有数值定义：跟随30%、明确追涨40%、询问20%、喊涨10%；已追买=1、计划=0.7；每账户最多3条。L1–L5不用于当前评分。题材发现日报继续沿用未知账户超过50%时隐藏综合分的门槛；旧方法结果不被悄悄改标为新方法。

`config/trading-calendar.json` 仅集中仓库原有的2026年休市日期，没有新增未经核验的年份。Python与TypeScript沿用北京时间15:30的“收盘数据可用”窗口；该时点不是交易所收盘时刻。前端在未知年份不声称知道最近交易日。

## 二、分别显示日期、方法与覆盖

社区观察、盘后报告和市场行情分别显示交易日、采集时间和快照方法版本。日期过旧、方法不一致和来源不完整是不同问题，不合成一个“可信度分数”。页面时间判断在客户端初始化后进行，服务端首次渲染保留稳定状态。

选历史日期时显示“正在查看历史快照”，而不是把正常的历史查看当作更新故障。报告和行情保留独立历史日期，并提供回到最新快照的入口；切换日期过程中到达的旧刷新响应不覆盖新选择。独立即时资金榜仍不随历史日期回放。

升级代码不会触发数据采集或重算。`start_dashboard.cmd`只启动看板，但资金组件本身仍会读取公开平台；`run_daily.cmd`才会执行现有更新流程及按已有配置决定的模型汇总。此次升级没有运行更新脚本，也没有改动密钥。

## 三、报告质量审计

新增质量面板分别展示有效采集入口、完整窗口入口、已经发布综合分的题材数量及高未知率题材数量。每个题材展开后可核对样本数、正文来源、未知拆分和不出分原因。题材之间可能共享股票和账户，不能把题材账户数相加成全市场人数。

新生成的报告新增以下可选元数据，旧快照缺字段时显示“未记录”：

- `meta.qualityVersion`、`meta.marketTradeDate`、`meta.marketCollectedAt`、`meta.feedComplete`；完整入口按去重股票集合计算，不跨题材累加。
- `expressionProfile.sampledAccounts`、`unmatchedAccounts`、`unsampledAccounts`。未知账户拆分满足“已抽样但规则未命中 + 未进入分析样本 = 原未知账户数”，不会改写既有分母或把未知重分类为中性。
- `observation.unknownAuthorPosts`：账户标识缺失的帖子数，和未知账户数分开。
- `observation.contentCoverage`：明确正文、仅标题、未标注类型和文本总量；只有明确来源标注或经过原帖身份核验的补读文本才计入正文。旧版的补读正文数量不能反推出全部正文覆盖。

规则命中率不是准确率；命中“转述/历史/警示”等辅助标签也不代表有追买行为。正式语义准确性仍需人工复核样本验证，本轮没有让大模型接管分类或改变门槛。

## 四、客观行情诊断

`sentiment/market_diagnostics.py` 是纯函数模块，不联网，仅接收已经由行情管线验证交易日与时点的股票记录。输出作为 `market.diagnostics` 保存，不参加韭菜分或历史综合温度。

| 统计 | 定义和缺失策略 |
| --- | --- |
| 净上涨广度 | 100 ×（上涨数−下跌数）/有有效当日涨跌幅的股票数。无有效股票时为空，不填零。 |
| 个股换手率中位数 | 对有当日有效非负换手率的股票计算中位数，并展示覆盖数量。 |
| 涨跌分布 | 分为 ≥5%、0～5%、平盘、−5～0%、≤−5% 五个互斥区间。5%仅为描述阈值，不是涨跌停判断。 |
| 前10股成交额占比 | 前10只股票成交额之和 / 同来源完整A股成交额。要求证券目录完整、全部当日成交额完整、至少10只股票且总额大于零；否则为空并显示原因。 |

相同股票记录去重；内容冲突的重复股票不参与计算。无效数值、负成交额、布尔值和非当前日期数据不冒充有效观测。部分覆盖可以显示已采样范围的分布，但不冒充全市场。

历史快照没有逐股诊断时，只从原有且可核对的涨跌家数计算净上涨广度；不把当前行情拼入历史，也不反推分档涨跌、换手中位数或集中度。下一次市场更新会保存新增字段。涨停、炸板和连板晋级暂未接入专用数据源，没有用阈值估算代替。
