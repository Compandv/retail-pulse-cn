# 表达分类复核：AI 预标注 + 人工抽查（2026-09-29）

动摇度（恐慌表达）、回补力（回补表达）、恐贪情绪（看涨/看跌）和追涨表达都建立在逐帖的规则判断上。本流程检验这些规则准不准。

“贪婪”与“恐慌”成对，范围比追涨宽。现有规则里只有追涨判断属于贪婪一侧，所以用它作为贪婪的规则预测；两者口径的差距本身就是要量的内容。原有的追涨账户级复核见 [BEHAVIOR_AUDIT_TRIAL](BEHAVIOR_AUDIT_TRIAL.md)。

## 为什么不全交给 AI

标注用来检验规则。如果标准答案全由 AI 给，量到的只是“规则和 AI 是否一致”。因此：

1. AI 标注整份样本，每条附理由，拿不准的标“存疑”。
2. 人工**盲标**一部分：80 条随机抽查，加上全部 AI 存疑条目。页面上看不到 AI 或规则的判断。
3. 先算 AI 与人工的一致率，再用参考标签评估规则：有人工标签的以人工为准，其余用 AI 非存疑标签。
4. 一致率达到约 90%，AI 标注才可以作为扩大样本的参考；否则规则评分只看人工部分。

## 标注口径（expression-review-1.1）

第一轮人工抽查（见下文）表明，按 1.0 的窄口径，人工和 AI 的理解差异很大。2026-10-07 起按人工的直觉改为下面的口径：**恐慌、贪婪标情绪，方向标判断，回补标“跌了想买”的意愿**，四项各自独立判断，同一句话可以同时满足多项。

| 字段 | 取值 | 口径 |
|---|---|---|
| 恐慌（情绪） | 是 / 否 | 帖子流露害怕、悲观、慌张、绝望：担心大跌或崩盘、觉得“完了”、急着跑、被套的痛苦、割肉止损。例：“大盘大跌，啥都会带崩”“这不得套几年”。没有情绪色彩的冷静分析（“缩量下跌，看 20 支撑”）记为否，只算方向；劝别人“别慌”记为否。 |
| 贪婪（情绪） | 是 / 否 | 帖子流露想买、急着上车、亢奋、幻想大涨：看好并想进场、追涨、满仓重仓、怕踏空、“要起飞了”。例：“被低估，重点关注”“重仓猛干”。没有情绪色彩的冷静判断记为否，只算方向。 |
| 方向（判断） | 看涨 / 看跌 / 都有 / 无 | 作者认为会涨或会跌；“先跌后反弹”记为都有；看不出判断（陈述事实、提问、闲聊）记为无。带不带情绪都照常判断。 |
| 回补（跌了想买） | 是 / 否 | 抄底、低吸、补仓、等回调或跌停再买、卖飞后想买回；“跌到 X 就买”也算。可与贪婪同时为是。 |

只按显示的文字判断，不点开链接。文字被截断、看不出来时选“拿不准”，不计入比较。

1.0 口径（第一轮使用）：恐慌只算作者本人亏损、割肉、崩溃；贪婪只算本人亢奋式买入（追涨、满仓、怕踏空）；回补只算补仓和卖飞想买回，条件句不算。

## 抽样

- 来源：某日复盘采集记录中全部当日帖子，按日报的方式处理，核验正文会替换标题。
- 按规范化文本去重后，按“任一规则是否命中”分成两层，各取一半（默认共 300 条），顺序按哈希固定。
- 规则命中的帖子只占约 18%。分层是为了抽到足够多的阳性样本；评估时按“层内总数 ÷ 层内抽样数”加权，还原到全部去重文本。
- 结果只描述文本分类表现，不是账户比例误差，也不是市场预测准确率。

## 命令

```bash
python scripts/expression_review.py sample --date 2026-09-28     # 抽样，写 sample-blind.jsonl、rule-predictions.json、meta.json
# AI 标注写入 ai-labels.jsonl：{id, panic, greed, direction, rebound, unsure, reason}
python scripts/expression_review.py queue --date 2026-09-28      # 生成人工抽查队列 review-queue.jsonl
# 浏览器打开 scripts/expression_labeler.html，载入 review-queue.jsonl，标完 Ctrl+S 保存
python scripts/expression_review.py evaluate --date 2026-09-28   # 写 evaluation.json
```

文件都在 Git 忽略的 `work/expression-review/<日期>/`，包含公开原文和链接，但不含账户标识。已存在的样本和队列不会被覆盖。

## 第一轮（2026-09-28）

- 当日处理帖子 37,959 条，去重后 36,453 条：规则命中 6,611 条，未命中 29,842 条，各抽 150 条。
- AI 标注 300 条，存疑 100 条，主要原因是标题被截断在 40 字、反讽或指代不明。
- 人工抽查队列 157 条（80 条随机 + 存疑，两者有重叠）。
- “贪婪”是标注开始前加入的。本样本分层时没有用追涨规则，贪婪的评估仍按同一权重还原，但阳性样本较少。追涨规则在 36,453 条去重文本中只命中 60 条（0.16%）。

**人工抽查结果（2026-10-07，1.0 口径）**：人工完成 150 条。AI 与人工的一致率为恐慌 64%、贪婪 75%、回补 77%、方向 56%，都远低于 90%。分歧几乎都是人工判“有”、AI 判“无”，说明主要是口径理解不同，而不只是判断失误：

- 人工把“大盘大跌，啥都会带崩”“砸的真狠”算作恐慌，即看空的害怕情绪；
- 把“被低估，重点关注”“资金抄底科技股”算作贪婪，即想买、看好；
- 把“等跌停了买一手”“明早低吸的机会”算作回补，即跌了想买。

按人工标注，在 74 条随机抽查样本上加权估计：恐慌约占 45%，贪婪约 30%，回补约 22%，看涨约 31%，看跌约 49%。规则的召回率：

| 判断 | 规则精确率 | 规则召回率 |
|---|---|---|
| 恐慌 | — | 0% |
| 贪婪（规则＝追涨） | 0% | 0% |
| 回补 | 33% | 3% |
| 看涨 | 67% | 26% |
| 看跌 | 79% | 22% |

样本小，数字波动大，但结论明确：**无论哪种口径，现有规则都漏掉了大部分表达**。因此口径改为 1.1，下一步按新口径重标，并在另一天的新样本上盲测 AI 与人工的一致率；达到约 90% 后再据此改进规则或改用模型分类。
