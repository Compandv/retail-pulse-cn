# V4 方法与实施记录

实施日期：2026-09-05。当前方法版本：MVP-4.0。

## 为什么改

V3 把讨论热度、新手、追涨、恐慌与多空方向混成一个加权分。即使讨论非常活跃，只要其余词典信号少，综合分仍然可能只有约 20。它无法回答“这一天市场到底热不热”。本次将问题拆成独立可观察量，不把目标视频里的分数当作训练标签，也没有声称取得博主未公开的后端公式。

## 四组观测

1. **社区关注热度**：同来源、同篮子、同日内时段的去重活跃账户数，相对之前最多 60 个有效日的经验分位。至少 20 日，当前覆盖完整且账户标识无缺失才出分。等值按半个历史日计。
2. **成交活跃分**：当日成交量在自身此前最多 60 个日线观测中的分位。每股至少 20 个有效历史成交量，篮子至少 70% 成分有基线；对这些成分等权平均。另显示上涨率、涨跌幅、换手率及成交量相对前 20 日均值。高分可发生于上涨或下跌，需结合行情方向解读。
3. **表达比例**：追买自述和明确追涨意愿进入追涨占比，恐慌独立计数。询问、看涨期待、普通买入、劝阻、转述与历史回顾分开标注。分母是去重及作者限量后的全部有效表达，包含一般讨论。
4. **L1–L5 表达构成**：L1 基础求助；L2 跟随判断；L3 策略描述；L4 风险推演；L5 证据研究。无法判断单列，不以追高、亏损或行情上涨作为经验等级依据。分母包含未知，因此不会只对少量可分类文本重新归一到 100%。

其中经验分位为：

```text
percentile(x) = 100 × [count(history < x) + 0.5 × count(history = x)] / N
basket_activity = mean(member_activity with valid history)
chase_share = 100 × chase_expression_count / all_analyzed_expressions
```

上述分位与比例不再加权形成综合分。20/60 日、作者最多三条及 70% 覆盖门槛都是明示的工程参数，尚未以人审或收益回测证明最优。

## 9 月 4 日猪肉案例

固定交易日 `2026-09-04`、北京时间 `00:00–15:00`。本次原始帖子采集于 `2026-09-05T15:26:39+08:00`，随后使用相同采集文件重算并补取对应日期行情。

篮子包括牧原、温氏、新希望、罗牛山、新五丰、正虹、天邦及大禹生物。大禹属于饲料添加剂/动保关联观察，并非纯养猪公司；该篮子不是官方行业指数，也不是所有猪肉股。

| 成交活跃分 | **95.2 / 100** | 7/8 成分取得成交量历史基线，各股分位的等权均值 |
| 有报价成分上涨 | **8/8** | 配合成交分位，可见上涨与交易活跃同时存在 |
| 东方财富已观察账户 | **705** | 观察到账户数下限，不是所有散户或持仓人数 |
| 有效讨论 | **1,014 条** | 去重与噪声过滤后、每账户三条限量之前 |
| 每日多来源分析样本 | **933 条** | 作者限量后，来自东方财富及辅助来源 |

分位 95.2 的含义与视频里的讨论度 93 不同；两者接近不是算法准确的验证。这个案例说明成交维度可以呈现原混合分掩盖的活跃现象。

在线真实接口复核：`猪肉` 返回 8 股篮子、705 个已观察账户、911 条东方财富分析样本、成交活跃 95.2；`920970` 返回 `bj920970 / 大禹生物`、价格 7.58、26 条窗口内分析样本。大禹公开历史成交基线不可得，因此个股成交分保留未知。每日与在线表达样本数差别来自来源不同，不表示两个计算器使用不同公式。

## 数据契约与保护

- 日期：只接受所选日截至 15:00 的发布时间，不把最后回复时间当发帖时间。回溯查询不使用之后的行情。当前日期校验内置 2026 年交易所休市日，需要按年度维护。
- 覆盖：每股最多 6 页；只有读至末页或连续两页的非置顶帖发布时间及活动时间都早于日期起点，才标记列表窗口已覆盖。重复页、超时、上限截断保持不完整。该状态不代表全平台或全市场覆盖。
- 去重：同来源、同作者的相同规范化文本去重；不同账户说同样的话仍分别保留。先计算观察量和账户数，再按每来源每账户最多三条限量分析。缺失账户标识不合并成一个人，也不作为有效的账户历史基线。
- 主题：代码和公司名查个股；配置的主题查篮子。23 个既有主题仍只有单股代理，会显式标明。观察池账户分母取并集，跨主题可能重叠；不能据此判断哪个完整行业散户最多。
- 历史：只纳入方法、来源、成员集合、时段一致的完整实测记录；排除当日、未来、旧方法、估算、缺失值。同日重跑幂等替换，读取每日文件恢复历史，成员个股基线分别保存。
- 故障：无当日有效样本不覆盖旧快照；旧日期回放不得覆盖更新日期。旧方法先归档，旧曲线与新曲线独立。
- 隐私：本地捕获中的作者标识哈希化，公开快照不包含作者字段；证据保留匿名文本、内容类型、时间、规则理由与可用原帖链接。

## 已完成验证与实际边界

完成 29 项 Python 测试、12 项 Node 测试，生产构建、TypeScript 检查与 ESLint 均通过。测试包含跨语言分类与聚合一致性、语境正反例、日期边界、重复分页、代码映射、缺失值、历史污染隔离、故障不覆盖、归档重跑、服务端渲染以及股票/主题查询集成。另实际调用本地在线接口核对上述猪肉与大禹结果，展示节选均位于目标日期窗口。

这些检查验证实现行为，不提供模型准确率。当前有三个主要限制：

1. 主要语料仍是公开标题或摘要，完整正文与回复覆盖不足。L1–L5 因而常为未知，且无法从言论验证实际交易。
2. 有限分页会在热闹日期产生截断。只保留完整历史也可能偏向较冷清日期；未来需改善持续采集覆盖，不能仅靠放宽评分门槛解决。
3. 当前是共享配置驱动的语境规则，仍可能误判反讽、跨句转述或复杂条件；未训练模型、未做独立人审校准，未确认博主公开了可复现方法。

下一阶段评估应覆盖不同日期、涨跌环境和板块，对“明确追买/询问/期待/否定/转述”等建立人工标注集；分别报告各类精确率、召回率、未知率和来源覆盖。L1–L5 只评表达特征，不能以收益或一句发言作真实投资经验标签。模型迭代也应保留规则和证据，按新方法版本重新积累基线。
