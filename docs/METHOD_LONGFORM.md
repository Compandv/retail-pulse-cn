# 复盘长图：日报与周报方法

版本：日报 `longform-daily-1.0`，六维 `report-dimensions-2.0`，周报 `weekly-report-1.0`，涨停生态 `limit-ecosystem-1.0`。设计方案见 [plans/longform-report-2026-09-27](plans/longform-report-2026-09-27/spec.md)，参数集中在 `config/longform.json`。

版式参考外部"韭菜指数"日报与周报。参考图说明其六维分数为"基于公开讨论的定性推导"，因此本项目只借鉴版式与维度名称，每个分数都由公式从采集数据计算，缺数据时显示"—"。

**本页内容是公开数据的统计与规则分类，不构成投资建议；分数和标签描述题材之间的相对位置，不是买卖信号。**

## 页面

- `/report?date=YYYY-MM-DD`：日报长图。
- `/weekly?week=YYYY-Www`：周报长图。
- 两页都可"导出长图 PNG"，在浏览器本地生成，不上传。

## 数据来源

| 数据 | 来源 | 说明 |
|---|---|---|
| 涨停、炸板、跌停、昨日涨停池 | 东方财富涨停板行情（`push2ex.eastmoney.com`） | 只保留约 15 个交易日，必须每日采集 |
| 指数日线 | 腾讯日线（上证、深成指、创业板指、科创 50） | 生成时读取，可回溯约 700 个交易日 |
| 两融余额（全市场） | 东方财富数据中心 `RPTA_RZRQ_LSHJ` | 次一交易日公布，展示最近已公布日期 |
| 行情、十强题材、资金、体温计 | 本项目已有的市场快照与盘后复盘 | 见 [复盘方法](METHOD_DAILY_REPORT.md) |

### 涨停池接口的实测行为（2026-09-27）

- 返回的 `qdate` 是接口所知的最新交易日，**不是**数据日期；请求历史交易日时 `qdate` 仍是最新日，但数据是所请求日期的。
- 请求非交易日时，接口会改为返回最新交易日的数据。因此程序只请求交易日历内的交易日。
- 请求超出保留期的日期时，四个池都为空。涨停、炸板、跌停三池同时为空时，判定为超出保留期，不保存。
- **交叉核对**：D 日"昨日涨停池"应基本等于 D−1 日"涨停池"。对上率低于 90% 时，判定为接口返回了其他日期，拒绝保存。
- 首次回补 09-04～09-24 共 15 个交易日，逐日对上率 98–100%（差异来自停牌与新股）。
- 09-21～09-24 涨停家数为 103、63、51、52，参考周报为 105、65、51、53。指数周涨跌与参考周报逐项一致。

## 涨停生态指标

| 指标 | 公式 |
|---|---|
| 涨停、跌停家数 | 各池条数（接口 `tc`） |
| 炸板率 | 炸板池数 ÷（涨停池数 + 炸板池数）× 100% |
| 连板高度、梯队 | 涨停池 `lbc` 的最大值；按 1、2、3、4、5+ 板计数 |
| 晋级率 | 昨日涨停池中今日仍涨停的数量 ÷ 昨日涨停数 |
| 昨日涨停今日表现 | 昨日涨停池今日涨跌幅的等权平均和中位数；连板子集（昨日 ≥2 板）少于 3 只时不出 |

以上都是描述统计，不做"冰点、主升、退潮"一类的阶段判断。

## 主线与涨停集中度

- **当日主线**：十强题材中成分涨停最多的题材，并列时取涨幅更高者。
- **涨停集中度**：主线成分涨停数 ÷ 全市场涨停数。
- 与参考图"浓度"（L1+L2 散户占比）含义不同，因此采用不同名称。

## 六维 v2

各维 0–100，"本表分位"指当天十强题材之间的分位：至少 5 个可比题材，并列取中位秩，0 值记 0。

| 维度 | 公式 |
|---|---|
| 热度 | 0.4 × 讨论度 + 0.6 × 题材成交额的本表分位 |
| 扩散力 | 0.5 × 传播力 + 0.5 × 讨论升温 |
| 动摇度 | 0.6 × 恐慌表达率的本表分位 + 0.4 × 放量下跌分 |
| 回补力 | 回补表达率的本表分位 |
| 拥挤度 | 换手率的本表分位 |

- **题材成交额**：成分股当日成交额之和，要求至少 90% 成分有值。
- **放量下跌分**：题材下跌且成交额高于前一交易日时，取跌幅绝对值的本表分位，否则为 0；前一交易日成交额不可得时为空。
- **回补表达**：原补仓表达，或"卖早了、卖飞、踏空、还能上车吗、回调接回、买回来"。排除否定、劝他人、转述和历史回顾；一条帖子只计一次。
- **总分（试验）** = 热度 30% + 扩散力 20% + 动摇度 20% + 回补力 15% + 拥挤度 15%。任一维缺失则总分为空。
- **追涨表达（试验）**作为第 6 维单独展示，不计入总分。

**局限**：本表分位是相对值，冷门的一天也会有题材得高分。题材自身历史满 20 个交易日后，另起方法版本改为和自身历史比较。

## 形态标签与拥挤提示

阈值：高 ≥ 65，低 ≤ 45。

- **形态**按以下顺序匹配第一条：高热高动摇、扩散低动摇、动摇有回补、降温（热度较前一交易日降 ≥10 且动摇度上升）、冷清（五维都低），其余为中性。
- **拥挤提示**：
  - 红：拥挤度 ≥ 75 且动摇度 ≥ 65；
  - 黄：拥挤度 ≥ 60 或动摇度 ≥ 60；
  - 绿：两项都不突出；
  - 灰：缺数据。
- 所有文案只描述位置，不含操作建议。

## 周报

- **周**：ISO 周内按交易日历的交易日。
- **发布门槛**：有长图的交易日达到 min(交易日数, max(3, ⌈60% 交易日数⌉)) 天，才发布周题材排名，否则只展示市场部分。
- **周题材分**：该题材出现各天日总分的平均，至少 2 天；各维度同理。取前 9。
- **市场部分**：
  - 逐日红盘率、成交额、涨停/跌停、炸板率、连板高度、主线；
  - 指数周涨跌：本周最后一个交易日收盘 ÷ 上周最后一个交易日收盘；
  - 资金：各日新浪主力净额相加，标注覆盖天数。
- **上周数字回顾**：只列上周值与本周值，不评判。
- **自动生成**：定时任务在每周最后一个交易日生成日报后，接着生成周报。

## 文字

- 默认使用模板文字，全部由计算字段拼成。
- 配置 API Key 后，可由模型生成标题、一句话、题材定性和周结论：
  - 模型只能以 `{{f:事实id}}` 占位符书写数字，由程序替换成页面上的原值；
  - 出现裸数字、未知编号、禁用词或超长时，该段改回模板文字；
  - 禁用词见 `config/longform.json` 的 `forbidden`。

## 命令

```bash
python scripts/update_limit.py --from 2026-09-04 --to 2026-09-24
python scripts/update_longform.py --from 2026-09-01 --to 2026-09-30
python scripts/update_longform.py --weekly-only --week 2026-W39
```

每日更新入口 `update_index.py` 已包含涨停生态与复盘长图两步，分别可用 `--only limit`、`--only longform` 单独运行。
