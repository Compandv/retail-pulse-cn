# 题材发现与关注排名（following-topic-2.0）

本版先采集候选题材讨论，再选前十。修复旧版先按涨幅、换手选十个概念、再在十强内部比较讨论的选择偏差。只在手动更新时采集；本地分类，模型只解读最终汇总。

## 数据与范围

1. 从所选交易日已核验的全 A 股行情，取成交额前180、涨幅前80、换手前60的并集，再补60只按交易日哈希固定抽取的股票。数量可在 `config/topic-discovery.json` 调整。
2. 读取东方财富个股 F10 的 `ssbk` 题材标签与 `hxtc` 主营业务关键词。来源接口：`https://emweb.securities.eastmoney.com/PC_HSF10/CoreConception/PageAjax?code=SZ300308`。标签属于采集时点，不充当历史成分。
3. 合并光通信模块/CPO、PCB/印制电路板等同义名称，排除地域、指数成分、风格、热股名单等标签。名称映射仅统一口径，不指定排名。同行业大类不自动继承所有讨论。
4. 主营关键词匹配或来源三级行业匹配的股票，可将其发言作为题材关注代理；其他标签需要帖子明确提及。此规则仍可能错配，不能保证每条帖子真正讨论该题材。
5. 每股最多读取6页公开列表；保存采集时间、日期、截断信息。计入所选日全天发言，包括盘后；回复数是采集时累计值。当前仍以标题为主，不宣称已读完整评论区。

原始记录保存在 `work/topic-discovery/日期/` 和 `work/report-observations/日期.json`。前端只发布汇总及代表文本，不发布账户标识。

## 排名公式

题材至少3只样本股、20个已观察账户，列表来源成功率和有效回复数覆盖均达到80%，才参加比较；至少5个达标题材才出排名。

- A：归属该题材的去重账户数。
- R：按账户限量、文本去重后的有效帖子，逐条计算 `ln(1+累计回复数)` 后求和，削弱个别爆帖的影响。
- 关注热度 = `0.65 × P(A) + 0.35 × P(R)`。
- 传播力 = `P(R)`。
- P 是本次全部达标候选题材内的百分位，不是十强内部重新打分。

关注热度描述总量，**不再除以股票数**；每股密度仅留作审计值。分数接近100表示本次候选样本内相对靠前，不是市场绝对火热程度。35%的互动权重属于试验参数，尚未有人审标注集或样本外验证。

按关注分排序后，若与已选题材的样本成分 Jaccard 重合率达到65%，跳过重复题材，继续补满十个。行业与概念可能仍有交叉，不能将人数、资金或帖子直接相加。表中涨跌和换手为样本股等权均值，不是官方板块指数。

## 六维与韭菜分

其余维度保持原公式，页面逐项解释。讨论升温需同股、两日完整窗口，截断不能当成增长。恐慌与追涨是表达占比，与关注分位的量纲不同。

韭菜分仍使用本地账户表达规则；**新版本未知账户超过50%时暂不发布综合点数**，保留原始输入与规则表达密度供核对。这个阈值是质量保护，不是统计置信度。无法识别不代表理性，不通过放大0.1分或套用参考图的45分来伪装校准。L1–L5不恢复。
