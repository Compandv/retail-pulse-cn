# 表达分层与韭菜分（试验版）

方法版本 `retail-profile-1.0`，启用于2026-09-06。用户要求分析后实现，恢复十强热点 L1–L5 分层及韭菜分。此方法与原 MVP-4.0 的停用等级字段独立；不认证真实经验、职业或盈利能力。

## 对用户方案的分析

方向可用于观察，但需要区分话题广度与分析质量。“美国加息”不能单凭术语判为 L5；认真做企业研究的人也不因未谈宏观而被认定能力低。此版使用发言呈现的证据层次，保留未知，给出判断理由。

金融素养研究使用基础及进阶知识问题，而不是按公开评论中的术语给人定级：[van Rooij、Lusardi、Alessie](https://www.nber.org/papers/w13565)。注意力研究将异常成交、价格变化、新闻作为不同代理：[Barber、Odean](https://faculty.haas.berkeley.edu/odean/attention.html)。这些研究支持明确观察变量的必要性，**没有提供本项目的 L1–L5 标准或权重**；下述规则和阈值为本项目待验证假设。

## 发言证据与账户分母

- L1：明确自述新手、基础追买求助，或缺乏分析的盲目跟随表达。询问不等于已经下单。
- L2：主力／技术／涨停叙事，尚未给出可核对的完整推理。
- L3：财报、估值或量价证据与自主判断、风险条件相联系。
- L4：政策或产业链传导关联企业经营，并提供论据与因果关系。
- L5：宏观因素连接产业／企业，有论据、连续传导链及风险情景。
- 仅复述新闻、引用、反问、只有术语、普通感叹、证据冲突：未知；不补成 L1。

每个来源账户在同一板块只计一票。沿用当日截至15:00、去重后每账户最多3条文本；多条可判定文本多数票决定层次，平票或跨越至少两级的冲突保留未知。一条强证据也可以产生初步分类，但单条证据账户数单列。交叉板块会重复覆盖同一账户，不相加为全市场人数。

设观察账户 A，已判定账户 K，L1和L2账户数合计 B：

- 卡片 L1–L5 比例：各级账户/K。柱条也仅表示已判定部分。
- 排序用 L1+L2 = 100×B/K。至少20个可判定账户、成分采样覆盖至少80%且有效文本至少20条才进入有效比例排名。
- 未知账户 = A−K，分类覆盖 = K/A。分别展示，不能把 B/K 说成全体散户占比。
- 未知全部归为高等级/低等级时，全部观察账户的 L1+L2 范围是 [100×B/A, 100×(B+A−K)/A]。

## 正文补采

公开列表多为截断标题，对长篇分析存在系统性遗漏。新增有界补采：每板块在已经选入分析的长标题（至少36字）中，以交易日和帖子ID稳定哈希选择最多64条，6个工作线程请求原帖。核对帖子ID、原始发表时间、板块代码与匿名账户一致后使用正文，最多1800字。

正文、核对信息和错误在 `work/profile-bodies/` 与私有原始报告中保存；公开报告仅输出汇总、部分证据、补采数量与实际观测时间。此采样偏向长文本，不是全市场随机样本；不降低未知比例门槛以强行出分。已保存的回复、转发、发表窗口、温度计及其他六维输入不因补正文而回写。后取正文可能已编辑，不能冒充收盘时已观测内容。

## 六维与独立韭菜分

六维：讨论规模、讨论升温、传播力、追涨倾向、恐慌倾向、交易活跃。旧补仓表达保留在证据明细，旧综合过热不再作为新六维的一列。

| 输入 | 当前计算 |
| --- | --- |
| 讨论规模 D | 去重讨论账户总数在十强可比板块中的分位；不再除以成分数量 |
| 讨论升温 G | 同一板块两日均完整的成分上，100×今日账户/(今日+前一交易日账户)，覆盖至少80%、两日样本各至少20条；50持平。历史较短，明确使用日环比，不冒充20日异常热度 |
| 传播力 S | 原记录每帖回复+转发均值的十强分位；仍是截至原采集时点累计量，不是当天增量 |
| 追涨倾向 Q | 本人追买行动/意愿文本占比；评分使用该比例的十强分位 Qr |
| 恐慌 F | 明确恐慌表达比例；修正“套牢盘”等分析性描述误判 |
| 交易活跃 T | 当日换手率相对来源全部概念的分位；不叫真实持仓拥挤 |

`韭菜分 = 0.35×L1L2 + 0.25×Qr + 0.10×D + 0.10×G + 0.10×S + 0.10×T`

定义为跟风过热观察，不衡量智力、投资能力或亏损概率。恐慌权重为0，既不加热也不减分抵扣风险。各项暂用正权重是候选模型假设，不能从相关性推导因果；资金/讨论活跃也可能有基本面原因。十强相对排名即使冷清也会出现高分，且输入有相关与重复计量风险。

配置位于 `config/retail-profile.json`。正权重输入缺任一项，结果为空，不补零、不临时改权重。分类覆盖至少50%且可判定账户至少20个才给点估计；否则只在其余输入完整时给未知账户上下界对应的范围。范围不是统计置信区间，不包含分类误判、截断、长文补采偏差。

旧版本首次重算前归档到 `public/data/report/archive/`，原始采集版本保持 `daily-report-1.0`，计算方法另存 `meta.analysisVersion`，不把重算当作新的历史交易日。

## 独立平台资金榜

`/api/fund-flow?source=eastmoney|ths&kind=industry|concept` 直接读取平台分页，目录完全由来源确定，不以本地新浪行业/概念过滤。每两分钟检查，服务端按来源和板块类型分别缓存，合并并发请求；失败保留同来源旧结果并标过期，部分分页标明不完整。即时榜与上方历史日期独立，新浪旧记录收在历史归档中。

- 东方财富采用官方资金页面脚本的 `f62` 主力净额、`f184` 净占比及大小单字段；返回日期来自 `f124`。
- 同花顺使用公开资金页面的流入、流出、净额（单位亿元）；保留“资金净额”名称，不冒充同口径主力净额。页面未给来源时点，界面明示未知，仅显示实际采集时间。
- 不相加交叉概念，不将两个平台同名板块金额平均。分页中发现重复、总数变化、缺字段或失败不宣布完整。
- 当前交付即时净额/可得净占比与价资关系评价。多日榜、15分钟增量和持续流入评价需另积累可靠同口径快照，尚未实现。

## 验证边界

语义反例、账户去重、未知、分数范围、恐慌独立、平台分页和单位有自动测试。它们验证实现与当前规则一致；尚无独立标注集的精确率/召回率，没有宣称分层已准确或已复现博主。
