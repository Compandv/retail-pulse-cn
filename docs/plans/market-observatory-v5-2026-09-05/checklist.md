# 拟议 V5 验收清单

状态：第一阶段已完成。下面是完整 V5 路线验收要求，不代表本期全部交付；本期已执行与待完成项目另见 [阶段记录](implementation-status.md)。L1–L5 按用户要求暂缓，相关实验验收保留为后续条件。

## R0：计算研究先于生产实现

- [ ] 每个候选指标明确测量对象、输入、公式、分母、0–100 含义、未知处理；论文原式与本项目改编分开。
- [ ] 对讨论规模、异常关注、多空方向、行为表达、群体过热和 L1–L5 分别定义，不互相代替。
- [ ] 标注规范包含引用、否定、询问、讽刺、历史行为及明确当日行动的对照例。
- [ ] 除单帖标注集外，账户等级使用多帖窗口样本，综合过热使用板块日样本，三者不能互相冒充。
- [ ] 比较关键词基线与语义模型，列出改判证据、逐类错误和未知/覆盖；讨论分另核查采样敏感性及排名稳定性。
- [ ] 人审标签不由涨幅、截图分数或模型自评直接生成；9 月 2/4 日不作为唯一校准日期。
- [ ] L1–L5 的候选门槛（3 条、2 天、2/3 一致性）只是实验基线，比较不同门槛后再确定；不足时未知，不默认新手。
- [ ] “行为分位 90”“追涨表达率 30%”“L1+L2 30%”能分别解释；无分类分母或低覆盖时不外推总体。
- [ ] 综合模型若采用 PCA，记录载荷、解释方差及跨期稳定性；若采用有序模型，记录标注一致性、留出误差和概率校准，不使用语言模型口述信心。
- [ ] 形成可复算的离线对照报告，再决定生产公式；公开文献调查完成不等于真实样本验证通过。

## P0：取数与口径

- [ ] 每类候选来源有真实样本或明确的不可用/权限说明，区分“文档有接口”和“已实测通过”。
- [ ] 核查 2026-09-02、2026-09-04 及至少一个普通交易日；缺历史数据如实记录。
- [ ] 样本覆盖沪深、创业板、科创板、北交所，以及停牌/ST/新股边界。
- [ ] 每项数值携带来源、统计日期、范围、单位、截止时刻、采集时刻和版本。
- [ ] 统一元/千元/万元/亿元、股/手的转换，并至少用一个真实样例核对。
- [ ] 明确沪深两市与沪深北 A 股的区别；指数成分成交不冒充交易所全量成交。
- [ ] 已确认预算与权限路线，未接入的付费源不会进入生产依赖。

## P1：用户可见的最小复盘首页

- [ ] 展示主要指数涨跌及明确范围的上涨/下跌/平盘数量、中位涨跌、成交额、较前交易日增减。
- [ ] 当全量行情未覆盖时显示覆盖状态；不以现有 31 股观察池冒充全市场。
- [ ] 每日同步来源可覆盖的完整行业/概念目录，展示候选总数、可计算数及缺口，榜单不被固定板块白名单限制。
- [ ] 任意满足覆盖条件的新板块在指标更高时可进入前列；军工、PCB、猪肉只作映射/轮动回归案例。
- [ ] 每个入榜方向可查看成员、所属类型、来源和日期；行业、交叉概念、北交所市场分组区分。
- [ ] 既有 24 个观察对象继续可用，尚未扩充者仍明确标为单股代理。
- [ ] 有每日重排的 TOP10 和由当天排名产生的前六重点卡片；覆盖或有效数量不足时说明，不用示例补位或固定方向占位。
- [ ] 至少验证两个热点不同日期的进榜/离榜与名次变化；名次下降不直接写成绝对降温，重叠主题不会占满榜单。
- [ ] 涨停、炸板、连板、N 天 M 板口径明确；若数据不可得，该区域显示缺失而不是零。
- [ ] 昨日涨停股今日表现使用前日确定的集合，不依据今天表现重新选样本。
- [ ] 当前日期和前日数据属于一致范围，单位与复权口径兼容。
- [ ] 从启动页面进入“当天 → 重点方向 → 成分/依据 → 返回”，能完成一次真实用户流程。

## P2：社区、资金和事件

- [ ] 正文、标题、摘要、回复的占比可见；原帖与引用文本不重复计数。
- [ ] 固定观察样本和新发现热点样本可区分，抽样规则有记录；同一股票多主题复用不会重复抓取。
- [ ] 热点额外抓取量不被误当成真实升温；社区主题可以独立入候选，未上涨板块不会被筛掉。
- [ ] 比较社区关注人数时同时展示采样覆盖；不能给不同范围直接加“全行业散户人数排名”的标题。
- [ ] 同作者刷屏受限，不同账户的相同表达不被全局合并；未知作者不当作一个共同账户。
- [ ] 阅读/评论/点赞区分累计值与两次采集间增量；不能将事后累计值标为 15:00 当时观测值。
- [ ] “新晋粉丝”“首次被本项目观察”“新手自述”是三个字段，不能互相替代。
- [ ] 板块资金展示来源、单位、截止时间、可用数量；不把单股资金量当板块资金量。
- [ ] 两个重叠概念的资金不会被相加成为全市场净流入；不由大小单推断真实机构/散户身份。
- [ ] 每个催化有原始出处、首次公开时间和关联对象；同一事件转载去重。
- [ ] 15:00 后首次公开的事件不写成当日盘中上涨的已知原因；允许单列盘后补充。
- [ ] 至少一个方向显示支持、反对或持续性不足的不同证据；无证据不生成结论。

## P3：语义和指标

- [ ] 首轮候选标注集建议不少于 600 条，覆盖至少 10 个方向、10 个交易日及不同涨跌环境；抽样方案和实际分布有记录。
- [ ] 至少 20% 样本由第二位标注者独立复核并处理分歧；若人审资源不足，明确保留实验状态。
- [ ] 训练/调规则与验证分开；留出集按日期并隔离重复文本/可关联作者，避免同源泄漏。
- [ ] 分类别报告精确率、召回率、混淆、样本量和未知率；同时展示现有规则结果，不只汇报总体准确率。
- [ ] 对“不要追高”“别人追了”“能不能追”“来个涨停”“昨天买过”“今天冲进去”等有成组正反例。
- [ ] L1–L5 不根据一次涨跌、亏损、追高或术语多少直接认定真实经验。
- [ ] 所有类型数加上未知数等于样本总数；四舍五入差异有处理，文本比例不冒充人数比例。
- [ ] 同一账户发 20 条仍计一个账户；跨平台身份不猜测合并，未知作者不当作一个共同账户。
- [ ] 对 1,000 账户、L1=120、L2=180、其他已分类=200、未知=500 的样例，显示全样本 L1+L2 为 30%、分类覆盖 50%；已分类内部 60% 不冒充全样本。
- [ ] 历史分位继续至少需要 20 个有效先前观测，当前日/未来/估算/旧方法不入基线。
- [ ] 五个市场位置与板块多维表均说明输入；无法证实的维度不为凑满版式强制打分。
- [ ] “补仓”显示表达比例；“拥挤”标明成交/讨论代理；“恐贪”若出分要说明方向和分母。
- [ ] 社区讨论分不由成交量替代；综合“韭菜分”先完成 R0 的定义与对照，再按讨论确定的范围接入。

## P4：日报、归档和连续验证

- [ ] 主要数字可追溯到确定快照字段，重要事件可展开原始来源。
- [ ] 事实、来源观点、模型推断在详情中可区分；日报不会补造缺失资金或社会画像。
- [ ] 次日情景有触发与失效条件；未经固定目标和样本外校准，不发布数字概率。
- [ ] 每份日报保存日期、生成时间、数据版本和修订历史；后续重算不冒充当时发布内容。
- [ ] 后一交易日可查看前日观察条件是否出现；不覆盖或事后重写原预测。
- [ ] 页面、详情、问答、导出的同一指标一致；导出含日期、来源口径和缺失说明。
- [ ] 09:30–15:00 新窗口若启用，与 V4 的 00:00–15:00 基线分开，盘前内容有独立说明。

## 技术与回归

- [ ] 原始采集和关联键保持私有，首页只载摘要，详情按需读；不把所有原文打包进首屏。
- [ ] 全部来源失败、单源限流、数据晚到、回放旧日、空样本等场景均不会损坏最新快照。
- [ ] 多来源不一致有来源级记录；版本和日期切换不会串数据。
- [ ] 920970 保持北交所映射，900901 等其他证券代码不误判。
- [ ] 保留当前股票/主题查询、历史、日历、证据筛选、问答、导出与旧版归档。
- [ ] 完成本阶段有关回归测试、构建、类型检查和 Lint；只报告实际执行结果。
- [ ] 端到端复核至少一次“真实日期采集 → 生成快照 → 首页 → 板块 → 证据 → 日报导出 → 次日回放”流程，并记录受访问限制而无法验证的部分。
