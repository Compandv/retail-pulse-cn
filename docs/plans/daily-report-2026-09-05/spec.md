# 市场复盘三件套

用户要求：五支市场体温计、当天十强板块六维表、主力资金流入／流出排名与评价，以及按数值和方向区分的色彩。沿用本地项目，不发布网站；L1–L5 继续暂缓。

目标是让用户先看市场冷热，再比较热点表达，最后核对资金方向。数据日期、采样范围、算法和缺项可展开；截图是呈现参考，不作为已验证公式或行情输入。

能力：

- 五支体温计分别展示成交、上涨广度、讨论升温、多空表达和高弹性交易板块成交占比。
- 从动态概念目录选出当日行情十强，对全部成分采集社区样本，展示六维热力表和原帖依据。
- 按行业／概念分别展示主力净流入与净流出榜，评价只描述价格与资金的关系。
- 统一冷热刻度、数值色阶和红涨绿跌；数值和标签同步保留，不依赖颜色单独传达含义。
- 日报按日期留存，支持回放，接入既有每日入口与看板。

非功能要求：匿名作者只留在私有采集；不把旧日资金当作当日数据；组合分缺任何必需输入时留空。方法说明区分描述统计、代理变量与试验综合分。

完成标准：三个模块使用真实数据可读可用，界面有日期和依据，来源失败与日期边界通过验证。未包括真实账户经验分类、交易建议、人工语义准确率证明及网站发布。
