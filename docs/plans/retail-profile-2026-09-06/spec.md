# 分层、韭菜分与独立资金榜

用户授权：先分析方案，再实现。温度计公式保留；恢复 L1–L5 研究并实现十强分层卡片。继续本地开发，不发布、不替换已有历史来源。

## 方法判断

用户给出的等级体现分析广度，但提到政策、宏观术语并不证明分析能力。采用发言内容推定的分析层次，结合论据、因果链和风险条件；不验证真实职业、投资年限或收益。普通行情评论不能默认归为 L1。保留未知和冲突，按账户聚合，公开摘要不输出作者标识。

六维采用讨论规模、讨论升温、传播力、追涨倾向、恐慌倾向、交易活跃。综合韭菜分单列，定义为跟风过热观察。L1+L2 与追涨为主要输入，恐慌单独描述，既不加热也不抵扣。分位、比例与两日温度分别标明，模型未经样本外校准。

资金榜从平台全量分页排行独立获取，支持东方财富／同花顺、行业／概念，不沿用本地新浪目录筛选。同花顺净额与东方财富主力口径分开。日期、更新时间、部分采集、过期和失败必须可见；实时榜不写进历史日报。

## 完成标准

- 十强 L1–L5 卡片独立于温度计、六维和资金模块；按已判定样本 L1+L2 比例降序；未知和覆盖可查。
- 账户归类有可核对文本与判断理由，单条/多条证据可区分；冲突或证据不足保留未知。
- 韦菜分可展开权重、分母、区间和缺失原因；低覆盖不输出精确点估计。
- 已有采集可离线重算，不用新互动冒充历史；温度计公式不变。
- 真正请求外部平台的资金路由、独立刷新界面和失败状态可用；不混用不同来源字段。

## 范围边界

规则是初版可审计实现，非训练模型；无需外部模型密钥。不根据截图目标百分比调阈值。新增付费数据、真实投资者身份识别和自动交易不在范围内。
