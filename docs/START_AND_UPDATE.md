# 查看与更新分开运行

国内数据接口默认逐请求直连（新浪、东方财富、腾讯行情、淘股吧），避免系统代理导致SSL握手超时；不修改系统代理，不改变模型API的网络路径。如果本机必须通过代理访问这些来源，可在启动前设置 `$env:RETAIL_DATA_PROXY_MODE='system'`；默认值为 `auto`。`direct` 则令所有公共采集请求直连。此变量不控制模型请求。

只查看：双击 `start_dashboard.cmd`，直接启动已有看板，不进行整轮采集，不调用模型。网页现有实时资金组件仍按自身设置请求行情。首次启动开发服务器需要短暂等待，后续直接访问 http://localhost:3000/ 。请核对数据日期，网页打开不代表已更新。

更新全部：双击 `run_daily.cmd`。先打开已有看板，再在控制台更新，完成后刷新网页。每步立即显示开始，等待时每10秒显示阶段耗时，采集任务定期显示已返回数量。返回不等于数据有效，实际日期/覆盖核验通过才算更新成功。失败立即提示，继续其他独立模块。

最后显示 `运行结束：成功 X/Y，失败 Z；总耗时 … 秒`。模型解读未完成会另行提示，不影响已保存本地指标。双击的窗口停留，按键关闭。新日志机制只对重新启动的更新进程生效。

详细输出：`work/logs/update-日期-时间-进程号.log`。网页启动日志：`work/logs/dashboard.log`。日志在Git忽略目录。运行锁防止新版入口重复启动更新。

```powershell
# 不打开网页、不等待按键；适合已有网页的终端使用
.\run_daily.cmd -SkipOpen
# 只更新市场目录及行情
.\run_daily.cmd -SkipOpen -Only market
# 只更新社区测量
.\run_daily.cmd -SkipOpen -Only community
# 只更新复盘，需要该交易日的有效市场快照，仍需采集社区/资金
.\run_daily.cmd -SkipOpen -Only report
```

这些改动提高启动和反馈体验，不承诺外部来源响应更快。耗时提示不是精确进度或剩余时间估算。Ctrl+C可请求中止，但正在等待的网络请求可能需要超时后才退出；已保存数据保留。来源失败时不会把旧数据伪装为今日数据。
