## 使用（Windows）

1. 双击 `run_daily.cmd`，采集最近已收盘交易日的数据并更新快照，完成后打开本地看板。
2. 只查看已有快照，双击 `start_dashboard.cmd`，或访问已运行的 `http://localhost:3000/`。
3. 股票查询输入 `920970`、`牧原股份` 或 `猪肉`，并选择交易日。代码和公司名查询个股；“猪肉”查询 8 股观察篮子。
4. 首页“今日板块轮动”可切换行业／概念、排序、搜索、历史日期；点击板块查看已保存的成分与行情。该榜每天更新来源目录，不受社区观察池限制。

```powershell
python scripts/update_index.py
npm run dev
```

需要 Python 3.10+、Node.js 22.13+；首次使用运行 `npm install`。Python 采集只使用标准库，无需配置账号、Cookie 或 API Key。在线日期校验当前支持 2026 年已收盘交易日。

仓库当前附带 2026-09-04 的真实采集快照。列表按**所选日期 00:00–15:00（北京时间）**过滤，旧帖和盘后帖子不计入该日表达。

动态市场首份快照已核验 49 个行业、175 个概念及来源目录内的 5,555 只 A 股收盘行情。[本阶段记录](docs/plans/market-observatory-v5-2026-09-05/implementation-status.md)列出真实核对结果、完成项与后续范围。

## 现在的数字如何计算

| 指标 | 含义 | 缺失时 |
| --- | --- | --- |
| 社区关注热度，0–100 | 同一观察篮子的东方财富去重账户数，相对自身此前最多 60 个有效历史日的分位 | 少于 20 个有效日、账户标识不全或当前采集不完整时显示“—” |
| 讨论升温，% | 当日去重账户数，相对最近 20 个可比有效日账户数中位数的增幅 | 基线不足、当前覆盖不完整或历史中位数为零时不出百分比 |
| 板块换手活跃，0–100 | 当日换手率在同类已取得行业／概念中的分位 | 缺少当日数据时显示“—”；不代表自身历史热度 |
| 板块历史换手分位，0–100 | 同来源、同板块换手率相对自身此前最多 60 日的分位 | 至少 20 个先前有效日；备用成分变化时重新积累 |
| 成交活跃分，0–100 | 每只成分股当日成交量相对此前最多 60 个交易日的分位，再对有基线成分等权平均 | 每股至少 20 日历史，篮子至少 70% 成分有基线才出总分 |
| 追涨表达、恐慌表达，% | 对去重、每来源每账户最多三条的分析文本计数，除以全部有效分析样本 | 空样本显示“—”；少于 20 条提示样本少 |

分位公式为 `100 ×（历史值低于当前值的天数 + 0.5 × 历史值等于当前值的天数）/ 有效历史天数`。

所有行情仅使用所选日期及此前日线。历史报价回退使用前复权参考价，界面展示具体来源；换手率等不可得字段不回填当前日期。成交活跃分不是散户净买入、实际追涨人数或未来上涨概率。

规则区分追买自述、追涨意愿、追买询问、普通买入、看涨期待、劝阻、转述和历史回顾。例如，“不要追高”不计入追涨，“来个涨停好不好”属于期待，“加仓，趋势向上，猛干”识别为追涨意愿。本期不根据评论推定作者真实投资经验。新复盘中的“综合过热”为明确标注的试验组合，尚未完成人工语义与样本外校准。

新增指标、来源及轮动规则见 [动态市场与讨论升温说明](docs/METHOD_MARKET_WATCH.md)，分级后续见 [L1–L5 暂缓记录](docs/DEFERRED_L1_L5.md)。原有表达规则见 [V4 方法说明](docs/METHOD_V4.md)；其中原等级定义仅为历史记录。[此前的公式审计](docs/SENTIMENT_METHOD_AUDIT_2026-09-05.md)与 [V3 使用说明归档](docs/README_V3_ARCHIVE.md)保留供追溯。

## 范围与来源

- **动态市场目录**：优先东方财富行业／概念／A 股列表，核对全部分页。接口不可用时使用新浪目录与成分，配合腾讯带日期的收盘报价；成功切换后沿用相同来源，避免每日混换分类体系。
- **备用板块口径**：有效成分等权涨跌与换手均值，至少 90% 成分有对应数据才出值；成交额要求全部成分金额完整。它与数据商的板块指数口径不同，页面明确标注。成分是采集时观察到的版本，不冒充过去盘中成分。
- **旧成分清理**：仅在当期 A 股目录完整时排除目录外原始成员，详情保留清单；不会把未抓到的股票直接认定为退市。
- **东方财富公开列表**：各标的最多 6 页 × 100 条，检测重复页、日期边界、超时与过滤后的样本。关注账户的时间序列统一使用此来源。
- **新浪股吧、淘股吧**：每日快照增加公开可见表达。在线查询当前只读东方财富，因此同日表达比例可能与每日快照不同。
- **腾讯公开报价和历史日线**：价格、涨跌幅、换手率，以及成交量历史分位。北交所 `920xxx` 正确使用 `bj` 前缀。

**社区**观察池目前共 31 只股票、24 个观察对象。“猪肉 / 养殖”使用 8 股自定义篮子，其余 23 个对象明确标为单股主题代理。它们并不具有同等行业覆盖，不能把社区表直接解读为全行业散户人数排名；动态行情目录尚未全部接入社区采样。一个账户可关注多个对象，关注份额之和可能超过 100%。

完整正文和评论回复尚未系统覆盖；正文不可得时使用标题，证据处显示内容类型。账户只是观察到的平台账户，不是已确认的个人或持仓人。分页不完整时数量是已观察下限，历史关注分留空。

## 历史、重算与故障

- 每日快照保存至 `public/data/daily/`，并更新 `latest.json` 和日期索引；同日重跑替换该日记录。
- 动态市场独立保存至 `public/data/market/`，已观察成分按日保存，市场总览按去重 A 股汇总，不叠加交叉板块金额。市场与社区更新分别处理失败，保留失败部分的上次结果。
- 历史分位只纳入同方法、同篮子、同来源、同截止时刻的完整实测数据，排除当日、未来、估算和旧版分数。个股与篮子分别积累基线。
- V3 最新快照归档至 `public/data/archive/`；旧历史保留在 `legacy`，图表独立展示，不与 V4 曲线连接。
- 核心列表全部失败、无当日有效样本、或试图用更早日期覆盖最新快照，均保留上一份可用结果。
- 私有原始采集保存于已被 Git 忽略的 `work/`，作者标识已哈希；公开快照去掉作者标识。采集时间与重算时间分别保留。

可用同一份采集记录重算，便于核对规则修改对结果的影响：

```powershell
python scripts/reprocess_observations.py work/v4-observations-2026-09-04.json
# 仅重新获取对应日期行情；不重新抓取评论
python scripts/reprocess_observations.py work/v4-observations-2026-09-04.json --refresh-trading
# 独立采集动态市场，或离线回放已保存采集记录
python scripts/update_market.py
python scripts/update_market.py --capture work/market-observations/2026-09-04.json
# 单独更新／离线重放新复盘
python scripts/update_report.py
python scripts/update_report.py --capture work/report-observations/2026-09-04.json
```

不要提交或公开 `work/` 中的采集记录。工具不会绕过登录、验证码、访问限制或证书检查。
