# 散户温度计

一个本地优先、可每日更新的 A 股社区情绪观察工具。它从无需登录即可访问的公开页面低频读取普通用户讨论，计算新手入场、追涨冲动、恐慌割肉、讨论热度和多空方向，并在网页中展示来源覆盖与置信等级。板块页还会展示最近升降温、样本占比、散户表达构成、赚钱效应代理、代表标的涨跌和公开主力资金流字段。

> 这是情绪观察工具，不是选股、择时或自动交易系统。高分不代表之后必跌，低分也不代表之后必涨。

## 直接使用（Windows）

1. 双击 `run_daily.cmd`：采集最近三个交易日的公开讨论并更新快照。
2. 脚本成功后会启动并打开本地看板 `http://localhost:3000/`。
3. 以后只看现有结果，可双击 `start_dashboard.cmd`。

终端运行：

```powershell
python scripts/update_index.py
npm run dev
```

首次换到另一台电脑时，需要 Python 3.10+、Node.js 22.13+，并先运行 `npm install`。Python 采集与评分只使用标准库，不需要账号、Cookie 或 API Key。

仓库默认附带一份标为 `demo` 的演示快照，确保断网时也能查看界面。首次成功采集后会自动替换为 `live` 实测快照。

## 数据来源

- 东方财富股吧：优先读取公开列表接口，失败时退回公开 HTML 列表。
- 新浪股吧：从公开论坛页发现论坛编号，再读取公开移动端列表。
- 淘股吧：只读取个股行情页中匿名可见的最新讨论块，不尝试登录后的翻页接口。

当前覆盖全市场入口和 24 个细分主题，分为科技、高端制造、金融地产、新能源车、消费医药、周期防御六组，例如 CPO 光模块、半导体设备、人形机器人、低空经济、光伏、锂电池、创新药和黄金。配置在 `config/targets.json`，可自行增加或替换代表股票。

公开端点可能变化、限流或临时不可用。程序不会绕过验证码、登录或访问限制：

- 至少一个来源有有效样本：生成 `live` 快照，缺失来源降低覆盖率并保留中性席位。
- 全部来源失败或近期无有效样本：不覆盖旧快照，脚本以失败状态结束。
- 网页始终展示每个来源的状态、样本数和说明。

行情与板块扩展字段是可选增强：全市场赚钱效应使用 24 个主题代表标的的上涨比例、中位涨跌和社区方向估算；单个板块赚钱效应使用代表标的涨跌结合社区信号。净流入使用东方财富公开的代表标的日线主力净流入；接口限流或字段缺失时显示“—”，不会把缺失伪装成零，也不把单只股票冒充完整板块。行情严格取快照交易日的收盘日线，不混入次日盘中数据。

## 指数含义

单条文本由透明词典和少量结构规则产生四个信号：

- `novice`：新手自述、基础求助、决策依赖、跟随表达。
- `fomo`：上车、梭哈、踏空、错失焦虑和确定性上涨表达。
- `panic`：亏损失控、割肉、清仓和逃离表达。
- `direction`：看空 `-100` 到看多 `+100`。

每个来源先独立聚合，再等权合并。综合温度使用讨论热度、新手、追涨、恐慌和方向绝对强度；低样本结果向 50 分收缩。历史只保留最近 60 个交易日，同一交易日重复执行会覆盖当天记录。每次运行都会从 `public/data/daily/*.json` 重建市场与板块历史，再合并当前快照，因此更换终端或重启后不会只剩最近一天。首次切换到实测后，程序会尝试从东方财富全市场公开分页回溯历史帖子，生成标记为“估算”的历史点；公开分页并不保证覆盖每个交易日，因此 10/20/60 日按钮表示“最近 N 个有观测交易日”，不会用 0 填补缺失日期。最新交易日始终标记为“实测”。

MVP 使用固定词典，容易误判反讽、谐音、复杂长文和新出现的社区黑话。正式用于研究前，应建立人工标注集并做滚动样本外验证。

## 隐私与内容边界

- 不识别真实“宝妈”，不推断性别、职业、年龄、家庭状态或投资经验。
- 原始用户 ID 只在内存中立即哈希，用于限制同一作者刷屏；不会写入快照。
- 网页不展示用户名、用户 ID、帖子编号或完整帖子，只展示聚合标签计数。
- 不采集需要登录、Cookie、验证码或规避反自动化措施才能访问的内容。
- 第三方网站条款与页面结构可能变化；商业使用前应取得相应数据授权。

## 自动更新

`.github/workflows/daily.yml` 会在工作日北京时间约 16:35 运行，并在快照变化时提交 `public/data/latest.json`。启用前请确认仓库允许 GitHub Actions 写入内容，并完成各来源的数据授权评估。

本地 Windows 也可以用“任务计划程序”在工作日 16:40 执行 `run_daily.cmd`。

## 目录

```text
app/                    网页看板
config/targets.json     来源入口与板块配置
public/data/latest.json 当前快照与最近 60 个交易日历史
public/data/daily/       按交易日保存的完整快照（用于重建历史）
public/data/index.json   可用交易日索引
scripts/update_index.py 每日更新入口
sentiment/              采集、清洗、评分与聚合
python_tests/           Python 单元测试
PLAN.md                 开发计划与完成标准
```
