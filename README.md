# 散户温度计：A 股社区情绪与行情观察

> [!WARNING]
> **投资风险提示：本项目仅用于信息观察与学术研究，不构成任何投资建议。**
> 页面上的所有分数、排名和解读都来自公开数据的统计与规则分类，可能延迟、缺失或出错，且分类准确率尚未经过人工验证。历史表现不代表未来，股市有风险，投资可能损失全部本金。请独立判断，必要时咨询持牌专业机构。完整说明见文末[投资风险提示与免责声明](#投资风险提示与免责声明)。

每个交易日收盘后，采集公开的 A 股行情和股吧讨论，在本机计算"散户在讨论什么、有多热、有没有在追涨"，生成一个本地看板。本地运行，采集只用 Python 标准库，不需要账号、Cookie 或 API Key。

## 适合什么场景

盘后复盘时，你大概想知道这些事：

- 今天哪些行业、概念涨得多、换手活跃？和它们自己过去的水平比起来算不算热？
- 股吧里讨论某只股票、某个题材的人，比平时多了还是少了？
- 讨论的人里，有多少是在明确说"已经追进去了"，而不是劝别人别追、转述别人，或者单纯喊涨？
- 主力资金今天流进、流出了哪些板块？

散户温度计把这些数字分开计算、分开展示：

- **行情热度和讨论热度分开看。** 一个板块可以成交很活跃，同时只有很少的帖子明确表示追买；两个数字回答的是不同问题，不合成一个"综合温度"。
- **每个数字都能追溯。** 点开温度、表格单元格，可以看到公式、采样覆盖和原帖。
- **数据不够就不出分。** 基线天数不足、采集不完整或未知比例过高时显示"—"，不给伪精确的数字。

## 能做什么

| 功能 | 说明 |
|---|---|
| 板块轮动 | 全部行业／概念的涨跌、换手和成交排行，可切换历史日期、搜索、查看成分股 |
| 市场体温计 | 五支体温计，外加客观行情诊断：净上涨广度、换手中位数、涨跌分布、成交集中度 |
| 十强复盘 | 当天行情前十的题材，从六个维度做热力表，可点开核对原帖 |
| 资金榜 | 行业／概念主力资金流入、流出双榜；另有直接读取东方财富、同花顺的即时资金榜 |
| 社区观察 | 31 只股票、24 个观察对象的关注热度、讨论升温、追涨／恐慌表达比例 |
| 跟风追涨表达 | 按账户去重的表达结构和"韭菜分"（试验指标），并列展示判断覆盖率与未知原因 |
| 指定日查询 | 输入股票代码、名称或"猪肉"等主题，在线查询某个交易日的讨论与行情 |
| 趋势与导出 | 10/20/60 日趋势、追涨表达日历、本地快照问答、PNG 观察卡导出 |
| 数据质量 | 每个模块单独显示交易日、采集时间、方法版本和采样覆盖 |

## 快速开始

需要 **Python 3.10+** 和 **Node.js 22.13+**。首次使用在项目目录安装前端依赖：

```bash
npm install
```

Windows 用户直接双击：

| 文件 | 作用 |
|---|---|
| `run_daily.cmd` | 采集最近一个已收盘交易日的数据并更新快照，完成后打开看板。耗时取决于数据源响应 |
| `start_dashboard.cmd` | 只打开已有快照的看板，不采集，也不调用模型 |

看板地址是 <http://localhost:3000/>。**请以页面上显示的数据日期为准**：网页能打开不代表数据已更新到今天。

其他系统或手动运行：

```bash
python scripts/update_index.py
npm run dev
```

## 使用方法

### 每天更新

收盘后（北京时间 15:30 以后）运行 `run_daily.cmd`。它先打开现有看板，再在控制台逐步更新，每 10 秒提示一次耗时，最后显示成功、失败了几个模块。更新完刷新网页即可。

市场行情、社区观察、十强复盘三部分独立更新：某一部分失败时，会保留它上一次的结果，其他部分照常更新。只想更新其中一部分：

```powershell
.\run_daily.cmd -SkipOpen -Only market      # 只更新市场目录与行情
.\run_daily.cmd -SkipOpen -Only community   # 只更新社区观察
.\run_daily.cmd -SkipOpen -Only report      # 只更新十强复盘
```

`-SkipOpen` 表示不打开网页、结束时不等待按键。详细日志保存在 `work/logs/`。

### 查询某只股票

在"指定交易日查询"中输入 `920970`、`牧原股份` 或 `猪肉`，并选择一个交易日。代码和公司名查询个股；`猪肉` 查询 8 只股票组成的观察篮子。在线查询只读取东方财富，因此比例可能和每日快照（多来源）略有不同。

### 查看历史

板块轮动和十强复盘都可以切换到历史日期，页面会提示"正在查看历史快照"，并提供回到最新快照的入口。

## 指标怎么读

| 指标 | 含义 | 什么时候显示"—" |
|---|---|---|
| 社区关注热度（0–100） | 当天去重发帖账户数，在自身最近最多 60 个有效交易日里的分位 | 有效历史少于 20 天，或当天采集不完整 |
| 讨论升温（%） | 当天去重账户数相对最近 20 个可比交易日中位数的增幅 | 基线不足或历史中位数为零 |
| 板块换手活跃（0–100） | 当天换手率在同类板块中的位置，不代表和自身历史相比 | 当天缺少数据 |
| 板块历史换手分位（0–100） | 同一板块换手率在自身最近最多 60 日里的分位 | 先前有效日少于 20 天 |
| 成交活跃分（0–100） | 各成分股成交量相对自身历史的分位，再等权平均 | 有历史基线的成分不足 70% |
| 追涨／恐慌表达（%） | 分析样本中被规则识别为追涨、恐慌表达的比例 | 没有样本；少于 20 条时提示样本少 |
| 韭菜分（试验） | 跟随 30% + 明确追涨 40% + 追涨询问 20% + 喊涨 10% 的加权表达率 | 观察账户少于 20 或未知账户超过 50% |

分位公式：`100 ×（历史值低于当前值的天数 + 0.5 × 历史值等于当前值的天数）/ 有效历史天数`。所有计算只使用所选日期及以前的数据。

几点需要特别注意：

- **这些数字描述的是"公开发言"，不是"真实交易"。** 成交活跃分不是散户净买入；追涨表达比例不是实际追涨人数；都不能用来预测涨跌。
- **分类靠规则，未经准确率验证。** 规则能区分"不要追高"（劝阻）、"来个涨停好不好"（期待）、"加仓，趋势向上，猛干"（追涨意愿）等语境，但目前没有完成人工标注评估，识别不到不等于不存在。
- **"韭菜分"只是指标名称。** 它统计的是账户发言中的跟风追涨表达，不是对任何投资者的评价，也不是身份、经验认证。
- **账户不等于个人。** 一个人可能有多个账户，一个账户可能关注多个对象；观察池只覆盖部分股票，不能当作全市场散户人数。

## 数据来源与边界

| 来源 | 用途 |
|---|---|
| 东方财富 | 行业／概念目录与成分、A 股列表、股吧帖子列表（关注热度统一用此来源）、资金流 |
| 新浪 | 东方财富不可用时的备用板块目录与成分；新浪股吧帖子 |
| 腾讯 | 报价、历史日线、换手率；备用板块口径的收盘数据 |
| 淘股吧 | 补充公开讨论 |
| 同花顺 | 即时资金榜 |

- 只读取公开可见页面，不绕过登录、验证码、访问限制或证书校验。
- 帖子按所选日期 **00:00–15:00（北京时间）** 过滤，盘后帖子不计入当天。正文取不到时使用标题，页面会标明内容类型。
- 备用板块口径（成分等权）和数据商的板块指数口径不同，页面会标注。
- 公开快照去掉了作者标识；私有原始采集放在 Git 忽略的 `work/` 中，作者标识已做哈希处理。
- 在线日期校验目前只支持 2026 年的交易日历。

## 可选：模型汇总解读

每日更新可以额外调用一次大模型，基于已算好的指标写一段汇总解读。**不配置也能正常使用**：本地指标照常计算，解读处显示"待配置 API 密钥"。

配置方法：把 `agent.env.example` 复制为 `.env.agent.local`（已被 Git 忽略），填写：

| 变量 | 说明 |
|---|---|
| `OPENAI_API_KEY` | 所选平台的密钥（变量名为兼容保留，不限于 OpenAI） |
| `OPENAI_BASE_URL` | API 基础地址，例如 `https://api.openai.com/v1`、`https://api.deepseek.com` |
| `OPENAI_API_TYPE` | `responses` 或 `chat_completions` |
| `OPENAI_MODEL` | 模型名 |
| `RETAIL_AGENT_MODE` | `shadow`（默认，只写候选分析，正式报告仍显示规则结果）或 `off` |

启用后，指标和部分原帖文本会发送到你配置的平台，费用由该平台计费。模型解读同样不构成投资建议。详见 [METHOD_AGENT](docs/METHOD_AGENT.md)。

## 数据、保留与备份

| 目录 | 内容 | 是否提交到 Git |
|---|---|---|
| `public/data/daily/` | 社区观察每日快照 | 是 |
| `public/data/market/` | 市场行情每日快照、板块成分明细 | 是 |
| `public/data/report/` | 十强复盘每日快照 | 是 |
| `public/data/archive/` | 旧版本快照归档 | 是 |
| `work/` | 私有原始采集、日志、复核样本 | 否，请勿公开 |

社区、市场、复盘各自的 `latest.json` 是最新快照，`index.json` 是日期索引。同一天重跑会替换当天记录；采集失败、没有有效样本，或试图用更早日期覆盖最新快照时，保留上一份可用结果。

**保留策略**：最近 60 个交易日完整保留。更早日期的社区快照移除原帖节选（约占 90% 体积），聚合指标和历史序列保留；更早的板块成分明细删除。运行 `python scripts/prune_data.py` 预览，确认后加 `--apply`。移除的内容仍可从 Git 历史和 `work/` 中找回。
