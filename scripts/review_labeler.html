追涨表达人工标注

离线使用：本页不联网、不上传。打开 work/behavior-audit/<日期>/review-sample-blind.jsonl，标注后保存回原文件，再运行 python scripts/evaluate_behaviors.py <文件>。进度会暂存在本浏览器中。

标注口径（behavior-audit-0.1）
  • target 追涨：作者本人明确表达已经跟随买入／追涨，或明确计划追涨买入。例：“加仓，趋势向上，猛干”。
  • non_target 非追涨：能判断作者当前没有追涨行动或计划：明确不追、观望自述、卖出／清仓自述、单纯提问、劝别人别追。
  • unknown 无法判断：文本截断、条件句（“如果…就买”）、转述他人、回顾历史、单纯喊涨或情绪、信息不足。拿不准时选 unknown，不要猜。
  • 只按页面显示的文字判断，不点开链接补充信息；若显示了“核验正文”，按标题＋正文整体判断。

快捷键：1 target · 2 non_target · 3 unknown · 0 清除 · ←/→ 上一条/下一条 · N 下一条未标注 · Ctrl+S 保存
